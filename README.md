# TechMitra

Professional IT company website — React, Vite, Tailwind CSS v4, React Three Fiber, GSAP/Lenis, Motion.

## Quick start

```bash
npm install
npm run dev
npm run build
```

## Stack
- React 19 + Vite 8 + JavaScript
- Tailwind CSS v4 (`@tailwindcss/vite`)
- React Router 7
- Three.js + React Three Fiber + Drei (procedural scenes)
- GSAP ScrollTrigger + Lenis
- Motion for route/section reveals
- Phosphor Icons

## Design system
- Source of truth: `design-system/techmitra/MASTER.md` (UI/UX Pro Max)
- Brand tokens: `src/styles/globals.css`
- Product / design contracts: `PRODUCT.md`, `DESIGN.md`

## Content
Editable data lives in `src/data/`. Sample projects, testimonials, and stats are labeled as placeholders — replace before production.

## 3D
Procedural scenes under `src/three/`. Optional GLB assets can be added to `public/models/` later.
