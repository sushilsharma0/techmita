#### Priority Issues

**[P0] Contact conversion destroys trust**
- What: Placeholder email/phone/address rendered live; form always succeeds then admits front-end demo (`ContactPage.jsx`, `company.js`).
- Why: Primary PRODUCT.md action is start a project conversation.
- Fix: Real or gated contact; wire form or honest mailto/calendar; success matching reality.
- Suggested command: `$impeccable harden /contact`

**[P1] Homepage is a content dump**
- What: `HomePage.jsx` chains 12 sections + CTABand with repeated Section3D + grid rhythm.
- Why: Buyers never get one job per scroll; CTA dilution; high cognitive load.
- Fix: Short arc — promise → how → 1–2 proof artifacts → FAQ → CTA.
- Suggested command: `$impeccable distill /`

**[P1] Proof valley — empty stats/quotes occupy trust real estate**
- What: `Stats.jsx` / `Testimonials.jsx` stage social-proof UI with dashes and Sample labels.
- Why: Mid-journey peak-end collapses where buyers seek proof.
- Fix: Remove or replace with non-fake proof (process artifacts, engagement model, security posture).
- Suggested command: `$impeccable quieter` / `$impeccable clarify` on home trust sections

**[P2] Nav IA overload and duplication**
- What: 7 primary items; Services mega ~10 links; About top-level and under Company.
- Why: Evaluation path unclear before first click.
- Fix: ≤5 top-level; nest About; mega → 4–5 featured + All services.
- Suggested command: `$impeccable distill` navigation

**[P2] 3D signature diluted to wallpaper**
- What: Section3D on nearly every home section and most interiors; non-interactive.
- Why: Signature becomes noise; hurts minimalism and mobile perception.
- Fix: One hero-scale scene per page; reserve section 3D for 1–2 beats.
- Suggested command: `$impeccable quieter` / `$impeccable optimize`
